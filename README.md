**Multilingual Shop-Script storefront: manual translation editor and JSON export/import.**

## Установка и загрузка

Для обычной установки используйте Инсталлер Webasyst и официальную карточку плагина. Архивы для ручной установки доступны в [GitHub Releases](https://github.com/The88788/multilanguageassyst/releases). Плагину нужны Webasyst, Shop-Script 11.1.0 или новее и PHP 7.4.24 или новее. Это не отдельное приложение для запуска без Webasyst.

Корень репозитория содержит файлы одного плагина. Его рабочая папка в Webasyst: `wa-apps/shop/plugins/multilanguageassyst/`. Архив релиза содержит папку `multilanguageassyst`. Автоматическое скачивание исходников GitHub не заменяет установочный архив релиза.

## Installation and download

Install through Webasyst Installer using the official store links above, or download the installation archive from [GitHub Releases](https://github.com/The88788/multilanguageassyst/releases). Requires Webasyst, Shop-Script 11.1.0 or later, and PHP 7.4.24 or later. This plugin does not run as a standalone application.

The repository root contains one plugin. Its installation path is `wa-apps/shop/plugins/multilanguageassyst/`. The release archive contains the `multilanguageassyst` folder. For manual installation, use the release asset rather than GitHub's automatically generated source archive. See the [English guide](README.en.md) for features, limitations, and setup.

Интерфейс админки доступен на русском и английском. Язык берется из настроек пользователя Webasyst. Языки витрины настраиваются отдельно во вкладке «Языки».

Плагин помогает добавить к магазину другие языки. Вы заполняете переводы вручную или загружаете их из JSON-файлов. Плагин не подключает платные API и не переводит текст автоматически.

## Что можно переводить

- Товары: названия, описания и другие поля, доступные в редакторе.
- Категории и страницы магазина.
- Названия характеристик и текстовые значения.
- Дополнительные услуги и их варианты.
- Подписи меню, кнопок, форм и сообщения витрины.
- Текстовые блоки поддерживаемых тем.

Исходные тексты остаются в магазине. Переводы хранятся отдельно в базе плагина. Админка не переводится.

Первая версия проверена с Shop-Script 11.1.0.1032 на темах insales и Webasyst2026. Подключение к теме описано в THEME-INTEGRATION.md. Для других тем может потребоваться адаптация. Поддержка блога и фотоальбомов в этой версии не заявляется. Готовая настройка SEO для всех языков также не входит в эту версию.

## С чего начать

1. Установите плагин и откройте «Переводы» в меню Shop-Script. Можно также открыть «Плагины» и выбрать МультиязыкАссист.
2. Откройте вкладку «Языки». Укажите язык исходных текстов и добавьте язык перевода. Казахский словарь входит в комплект, но казахский язык можно удалить и добавить свой.
3. Во вкладке «Публикации» выберите тип содержимого и язык перевода. Найдите нужную запись и нажмите её название.
4. Заполните перевод и сохраните. После сохранения откроется прежний список.
5. Переключите язык на витрине и проверьте результат. Если переключателя нет, подключите его по инструкции для темы.

В редакторе товара доступны его тексты и характеристики. При экспорте товары и характеристики выгружаются отдельно.

## Перевод через файл

Во вкладке «Экспорт» выберите содержимое, язык и нужные записи. Скачайте JSON, заполните перевод и загрузите файл во вкладке «Импорт». Сначала нажмите «Проверить файл», затем «Импортировать».

Меняйте только значения translation. Не меняйте ID, названия полей, source, source_hash и target_language. Язык импорта указан в target_language. Этот язык должен быть добавлен во вкладке «Языки».

Для замены существующих переводов включите «Разрешить замену существующих переводов». Файлы привязаны к магазину, из которого они выгружены. Не импортируйте их в другой магазин без проверки ID и исходных текстов.

Подробная инструкция и примеры запросов для ChatGPT находятся в TRANSLATING.md. Для проверки качества перевода обратитесь к переводчику или носителю языка.

## Меню, кнопки, услуги и блоки

Короткие подписи ищите в разделе «Фразы интерфейса». Там же доступны подписи оформления заказа, способов доставки и оплаты, валют и короткие тексты баннеров.

Услуги и их варианты переводите через «Дополнительные услуги и варианты». Их короткие подписи также можно найти в интерфейсе витрины.

Длинные тексты поддерживаемой темы ищите в текстовых блоках темы. При переводе сохраняйте HTML, ссылки и переменные. Не изменяйте официальные ссылки и условия показа копирайтов Webasyst и Shop-Script.

## Языки и журнал

Дополнительный язык можно удалить. Его переводы останутся в базе и снова будут доступны после добавления того же кода языка. Исходный язык удалить нельзя.

Журнал хранит последние 200 событий импорта и других операций. Старые события удаляются автоматически. Можно показывать по 20, 50, 100 записей или все 200. Полные тексты переводов и содержимое файлов в журнал не попадают.

## Если после обновления что-то не появилось

Обновление до 0.6.16 очищает кеш событий и загрузки классов. Если файлы загружены вручную или пункт «Переводы» не появился, откройте «Инсталлер», затем «Настройки» и нажмите «Очистить кеш». После этого обновите страницу браузера через Ctrl+F5.

Отключение плагина сохраняет переводы. Для управления плагином нужны права, которые настроены в Shop-Script. Не давайте доступ к настройкам магазина пользователям, которым он не нужен.

## Установка

Лицензия: LGPL, версия 3.


Установите плагин через Инсталлер, добавьте язык, заполните переводы и подключите тему по THEME-INTEGRATION.md. Адрес админки и папка сайта могут отличаться: открывайте плагин из меню своего Shop-Script.

Плагин частично совместим с возможностями ПРЕМИУМ. Он не меняет количество товаров, цены и суммы. Перевод названий единиц измерения не реализован. Полная проверка всех расширенных возможностей пока не проведена.

При удалении плагина через Инсталлер его таблица переводов и настройки удаляются. Перед удалением сделайте резервную копию. Отключение плагина сохраняет переводы.
