# Установка без маркета

[English](INSTALL.en.md)

Инструкция для установки на собственный сервер с доступом к файлам сайта. В облаке Webasyst используйте Инсталлер и доступные способы установки, которые предоставляет хостинг.

## Требования

- Установленные Webasyst и Shop-Script 11.1.0 или новее.
- Приложение «Инсталлер» версии 3.2.0 или новее.
- PHP 7.4.24 или новее с расширением mbstring.
- Доступ к файлам сайта и права администратора Shop-Script.

Плагин не содержит дистрибутив Webasyst или Shop-Script. Их нужно установить заранее.

## 1. Сделайте резервную копию

Сохраните базу данных и файлы сайта. Если плагин уже установлен, отдельно сохраните его папку и файл `wa-config/apps/shop/plugins.php`. Не публикуйте эти резервные копии в GitHub.

## 2. Скачайте архив релиза

Откройте [Releases](https://github.com/The88788/multilanguageassyst/releases) и скачайте приложенный установочный файл `multilanguageassyst-ВЕРСИЯ.tar.gz`.

Используйте именно этот файл, а не автоматически созданные GitHub архивы Source code. Распакуйте его с помощью 7-Zip, tar или архиватора хостинга. После распаковки должна получиться папка `multilanguageassyst` с каталогами `lib`, `templates`, `js`, `locale` и `img`.

## 3. Загрузите файлы

Скопируйте папку `multilanguageassyst` в каталог магазина:

```text
wa-apps/shop/plugins/multilanguageassyst/
```

Проверьте итоговый путь:

```text
wa-apps/shop/plugins/multilanguageassyst/lib/config/plugin.php
```

Внутри не должно быть второй вложенной папки `multilanguageassyst`. Копируйте все файлы, включая скрытые `.htaccess`. Пользователь веб-сервера должен иметь доступ на чтение файлов плагина. Не назначайте права 777.

## 4. Включите плагин

Откройте файл `wa-config/apps/shop/plugins.php` в текстовом редакторе. В существующий массив добавьте запись:

```php
'multilanguageassyst' => true,
```

Не удаляйте другие записи. Если ключ уже есть, измените его значение на `true`, не добавляйте второй такой же ключ.

Если файла нет, создайте его с таким содержимым:

```php
<?php
return array(
    'multilanguageassyst' => true,
);
```

Сохраните файл в UTF-8 без BOM. Если редактируете существующий файл, сохраняйте его структуру: показанная запись должна находиться внутри возвращаемого массива.

## 5. Очистите кеш и откройте плагин

1. В админке откройте «Инсталлер», затем «Настройки» и очистите кеш Webasyst. Это важно: после ручной загрузки может остаться старый кеш обработчиков событий и классов.
2. Обновите браузер через Ctrl+F5.
3. В Shop-Script откройте «Переводы» в боковом меню или выберите плагин в разделе «Плагины».

Для стандартного адреса админки можно открыть:

```text
https://ВАШ-САЙТ/webasyst/shop/?plugin=multilanguageassyst&module=backend
```

Если адрес админки или подпапка установки отличаются, используйте свой адрес Shop-Script. Таблица переводов создается автоматически при первой загрузке плагина средствами Webasyst. Вручную импортировать SQL не нужно.

## 6. Настройте языки и тему

Добавьте язык во вкладке «Языки». Проверьте ручной перевод одного товара или экспорт, проверку и импорт небольшого файла. Для вывода переводов и переключателя в вашей теме следуйте [THEME-INTEGRATION.md](THEME-INTEGRATION.md). Плагин не заменяет шаблоны темы автоматически.

Инструкция по переводу и промпты: [TRANSLATING.md](TRANSLATING.md). Язык интерфейса самого плагина берется из профиля пользователя Webasyst, отдельно от языков витрины.

## Обновление вручную

1. Сделайте резервную копию файлов и базы.
2. Скачайте установочный архив новой версии из Releases.
3. Загрузите его содержимое поверх файлов в `wa-apps/shop/plugins/multilanguageassyst/`. Не удаляйте плагин через Инсталлер перед обновлением.
4. Сохраните запись включения в `plugins.php`. Очистите кеш Webasyst и откройте страницу плагина: необходимые обновления выполняются штатным механизмом Webasyst.
5. Проверьте версию, сохраненные переводы и витрину.

Обновление не требует повторного импорта всех переводов. Если вы изменяли код плагина, сначала сравните свои изменения с новой версией. Измененные шаблоны темы обновляются отдельно.

## Отключение и удаление

Для отключения установите `'multilanguageassyst' => false` в `plugins.php` и очистите кеш. Переводы сохранятся. Подключения темы должны учитывать отключение плагина, как показано в инструкции по адаптации.

Удаление через Инсталлер удаляет таблицу переводов и настройки. Перед удалением сделайте резервную копию. Простое удаление папки не является полным удалением плагина из базы данных.

## Если не открывается

- Проверьте путь к `lib/config/plugin.php`, наличие всех файлов и запись в `plugins.php`.
- Проверьте требования PHP и права пользователя админки.
- Очистите кеш Webasyst и обновите браузер.
- Смотрите ошибки в `wa-log/` и журнале PHP сервера. Перед отправкой логов удалите пароли, данные покупателей и другую частную информацию.
