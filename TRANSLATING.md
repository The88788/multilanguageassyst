# Подготовка перевода без API

1. Войдите в админку своего магазина. Откройте «Переводы» в меню Shop-Script или выберите МультиязыкАссист в списке плагинов.
2. Во вкладке «Экспорт» выберите язык перевода и тип содержимого:
   товары, категории, страницы, характеристики или текстовые блоки темы. Дополнительные языки можно
   добавить во вкладке «Языки»; копировать JSON вручную для этого не нужно.
   Для меню, кнопок и сообщений выберите «Фразы интерфейса». Это отдельные файлы,
   которые импортируются тем же способом. В них входят общие фразы, короткие
   подписи меню и настройки поддерживаемой темы insales. Меняйте только translation;
   сохраняйте подстановки %s, %d и другие параметры. HTML в таких фразах не допускается.
   Найдите нужные записи по названию либо модели. Нажмите «Показать».
3. Отметьте записи галочками либо «Выбрать всю текущую страницу».
   Нажмите «Скачать выбранные тексты». ID плагин добавит автоматически.
   В одной партии до 100 записей. Для следующей партии нажмите «Следующие 100»
   над таблицей либо выберите номер партии и нажмите «Перейти».
   Список загружается без перезагрузки страницы. Галочки при переходе сбрасываются.
   Товары отсортированы от новых к старым. При добавлении товаров состав партий
   меняется, поэтому для продолжения выгрузки лучше использовать неизменный каталог.
   Номер партии и язык входят в имя файла. Например, для 1000 товаров нужны 10 партий;
   для первого теста достаточно одной партии или нескольких выбранных товаров.
4. Полученный JSON передайте переводчику. Файл содержит только выбранные
   публичные поля каталога, без пользователей, заказов и ключей доступа.
5. Переводчик заполняет только поля translation. ID, ключи и source_hash
   оставьте без изменений.
6. Во вкладке «Импорт» сначала проверьте файл и загрузите файл.
   Язык определяется по target_language в JSON и должен быть зарегистрирован
   во вкладке «Языки». Старые файлы ru_RU/kk_KZ остаются совместимыми.
7. Проверьте результат на витрине. Для замены существующего перевода требуется
   отдельное подтверждение. Пустые поля импорта не удаляют готовые переводы.
8. Для ручного заполнения во вкладке «Публикации» нажмите название записи. После сохранения
   откроется тот же список. Результаты операций можно посмотреть во вкладке «Журнал».
   В редакторе товара также доступны названия характеристик и его текстовые значения.
   Эти переводы общие для каталога: одинаковая характеристика/значение в других
   товарах получит тот же перевод. Экспорт характеристик остаётся отдельным.

## Выбор способа перевода

Плагин не требует платного API: экспортированный JSON можно перевести с помощью
ChatGPT или передать переводчику для ручного заполнения. ChatGPT подходит для
подготовки черновика. Для более качественного результата передайте исходные тексты
и черновик переводчику-лингвисту либо носителю целевого языка, желательно с опытом
перевода текстов интернет-магазинов. Можно сразу заказать ручной перевод без ChatGPT.
Особенно внимательно проверьте технические характеристики, условия доставки,
возврата и тексты оформления заказа. Плагин проверяет формат файла и соответствие
исходному тексту, но не оценивает качество языка или юридическую полноту версии.

## Как использовать готовые промпты

1. Выгрузите JSON во вкладке «Экспорт» и сохраните исходный файл отдельно.
2. Прикрепите в ChatGPT один файл и вставьте подходящий промпт ниже.
   Замените `[целевой язык]` нужным языком, например «казахский язык (кириллица)».
   Он должен соответствовать target_language файла: для казахского это kk_KZ.
3. Сохраните полный результат отдельным файлом с расширением .json в кодировке UTF-8.
   Если ответ показан как блок кода, в файл копируйте только JSON, без Markdown-ограждений
   и пояснений. Удобно использовать любой текстовый редактор.
4. Если ответ оборвался, не импортируйте неполный JSON. Сделайте меньшую выгрузку
   и повторите перевод. До 100 записей - предел плагина, а не гарантия, что большой
   текст поместится в ответ ChatGPT.
5. Проверьте перевод, затем выполните «Импорт → Проверить файл → Импортировать».
   Каждый файл загружается отдельно. Замену существующих переводов разрешайте
   только если намеренно хотите применить исправленную версию.

### Товары, категории, страницы и характеристики

Этот же промпт подходит для «Текстовых блоков темы»: дополнительно сохраняйте
theme_app, theme_id и setting_key без изменений. В них указана привязка к теме
и настройке. Перевод хранится отдельно, русские настройки темы не перезаписываются.

```text
Переведи тексты приложенного JSON на [целевой язык] для интернет-магазина.
Верни полный валидный JSON в исходной структуре, без пояснений и сокращений.
Изменяй только значения translation. Заполни пустые переводы; уже заполненные
переводы сохрани без изменений.
Не меняй format, source_language, target_language, source, source_hash, needs_review,
entity_id, entity_type, feature_code, feature_type, названия полей и структуру файла.
Если есть theme_app, theme_id и setting_key, сохрани их без изменений.
Сохрани исходную HTML-разметку, ссылки и адреса изображений без изменений.
Не добавляй HTML, скрипты, новые элементы или комментарии.
Сохрани артикулы, модели, бренды, числа, размеры и единицы измерения.
Переведи названия характеристик и текстовые значения, например названия цветов.
Не добавляй свойства товара, обещания или условия, которых нет в оригинале.
Подстановки %s, %d, %1$s и другие параметры сохрани точно и в исходном порядке.
Если пустое поле нельзя уверенно перевести, оставь translation пустым
для последующей ручной проверки. Не записывай пояснения вместо перевода.
```

### Меню, кнопки и сообщения: «Фразы интерфейса»

```text
Переведи фразы интерфейса интернет-магазина из приложенного JSON на [целевой язык].
Для кнопок и меню используй короткие, понятные формулировки и единые термины.
Верни полный валидный JSON в исходной структуре, без пояснений и сокращений.
Изменяй только значения translation. Заполни пустые переводы; уже заполненные
переводы сохрани без изменений.
Не меняй format, source_language, target_language, source, source_hash, needs_review,
entity_id, entity_type, названия полей и структуру файла.
Подстановки %s, %d, %1$s и другие параметры сохрани точно и в исходном порядке.
Сохрани числа, бренды, модели и технические обозначения.
HTML, дополнительную разметку и комментарии не добавляй.
Если пустое поле нельзя уверенно перевести, оставь translation пустым
для последующей ручной проверки. Не записывай пояснения вместо перевода.
```

### Проверка и исправление уже готового перевода

Этот промпт намеренно разрешает исправление заполненных translation. Его можно
использовать после первого перевода. Проверка ChatGPT не заменяет редактуру
переводчиком-лингвистом или носителем языка. При импорте исправлений могут появиться
замены: сначала проверьте файл, затем явно разрешите замену существующих переводов.

```text
Проверь перевод приложенного JSON на [целевой язык] по исходным значениям source.
Исправь ошибки в translation: смысловые неточности, грамматику, неестественные
формулировки и непоследовательные термины. Сохрани смысл и факты оригинала.
Разрешено менять только translation, в том числе уже заполненные значения.
Остальные значения, ключи, идентификаторы и структуру файла не меняй.
Сохрани HTML-разметку оригинала, ссылки, изображения, бренды, модели, артикулы,
числа и единицы измерения. Для объектов interface HTML не добавляй.
Подстановки %s, %d, %1$s и другие параметры сохрани точно и в исходном порядке.
Верни полный валидный JSON, без пояснений, комментариев и сокращений.
Не добавляй сведения, которых нет в исходном тексте.
```

## После импорта и очистка кеша

«Текстовые блоки темы» сейчас поддерживают тему insales: текстовые настройки
баннеров, преимуществ, заголовков, описаний и подвала. Изображения, URL, номера
телефонов и управляющие настройки не переводятся. Настройки со Smarty-кодом,
скриптами или неподдерживаемыми встроенными элементами не входят в этот экспорт.
Текст «О магазине» на главной берётся из страницы, выбранной в home_company_id:
его нужно переводить как страницу магазина. В теме подключён вывод её перевода.
Блоки других тем и произвольные HTML-блоки приложения «Сайт» требуют отдельного адаптера.

После импорта фраз обновите витрину. Шаблоны разных языков кешируются раздельно;
обновлённый словарь автоматически получает отдельную версию кеша. Динамические
подписи формы заказа обновляются в браузере без изменения введённых данных.
Длинные HTML-блоки, баннеры, тексты сторонних плагинов и блог не входят в короткие
фразы интерфейса: для них потребуется отдельное подключение перевода.

Если после установки/обновления отсутствует пункт «Переводы» в меню Shop-Script,
откройте «Инсталлер → Настройки → Очистить кеш», затем заново откройте Shop-Script.
Webasyst отдельно кеширует обработчики событий, поэтому одной перезагрузки браузера
иногда недостаточно. Переводы при очистке кеша не удаляются.


## Характеристики, версия 0.3.0

Экспорт характеристики включает название (name) и её текстовые значения
(value_ID), в том числе названия цветов. Значения заполняются отдельно от названия,
но входят в ту же запись JSON. В редакторе они показаны рядом с оригиналами.
Числа, размеры, единицы измерения, код цвета и артикулы переводить не нужно.
ID значений и характеристики действуют только в этом магазине. Не изменяйте
feature_code, feature_type, entity_id и source_hash. Импорт проверяет код/тип
характеристики и исходные тексты. Старые файлы с названиями остаются совместимыми;
для перевода значений нужно выполнить новый экспорт.

Карта в iframe: существующая карта Яндекса сохраняется в переводе. Разрешено перевести только атрибут title, оставив src, координаты, размеры и остальную разметку как в оригинале. Новые iframe и изменения адреса карты блокируются.

После проверки и импорта показано имя загруженного файла. Во вкладке «Журнал» сохраняются имена файлов новых операций, результат и количество полей; журнал хранит последние 200 операций. У старых записей имя файла отсутствует. Повторная загрузка одинакового перевода не создаёт дубликатов: количество изменённых полей будет 0. Отличающийся существующий перевод заменяется только при явном разрешении замены.

Видео: существующие iframe YouTube (/embed/ID) сохраняйте как в исходнике, включая src, ID ролика и параметры. Поддерживаются HTTPS и относительный протокол // для youtube.com и youtube-nocookie.com. Новые вставки и изменение ролика через импорт переводов не допускаются; добавляйте видео в оригинал товара и делайте новый экспорт.


## Теги и блог (0.6.0)

Экспортируйте «Теги товаров» и «Статьи блога» отдельно. Применяйте общий промпт выше: меняются только translation. Заголовок - title, текст - text, вступление - text_before_cut, подпись продолжения - cut_link_label. Теги содержат name без HTML. Ссылки и URL тегов не переводятся. Теги блога доступны, если соответствующий плагин создаёт таблицу blog_tag; его шаблон облака тегов требует адаптации.

Во вкладке «Языки» можно скрывать блог и теги отдельно для каждого дополнительного языка до окончания перевода. Оригинал остаётся доступным.


Услуги: выберите «Дополнительные услуги и варианты» в Экспорте. Поле name - название, variant_ID - название варианта. Сохраните ID и source_hash. Эти файлы предназначены для магазина, из которого получен экспорт. Подписи оформления заказа, способы оплаты/доставки и валюты переводятся как «Фразы интерфейса».

## Как переводить дополнительные услуги

Используйте отдельный раздел:

1. Откройте плагин → «Публикации».
2. В списке содержимого выберите «Дополнительные услуги и варианты», затем язык перевода.
3. Найдите услугу по названию и нажмите «Показать».
4. Откройте услугу, заполните перевод названия и названий её вариантов, сохраните.
5. Проверьте услугу в карточке товара и корзине на выбранном языке.

Услуга общая для каталога: её перевод используется во всех товарах, к которым
она подключена. Цены и настройки подключения услуги переводить не нужно.
После добавления новой услуги в Shop-Script переведите её таким же способом.

Для перевода через файл откройте «Экспорт», выберите «Дополнительные услуги
и варианты» и язык, отметьте нужные услуги и скачайте JSON. Переведите только
значения translation: name - название услуги, variant_ID - название варианта.
Сохраните остальные поля и ID. Во вкладке «Импорт» выберите готовый файл,
нажмите «Проверить», затем «Импортировать». Для замены отличающихся существующих
переводов отметьте разрешение замены. Файл предназначен для магазина, из которого
сделан экспорт.

Для услуг удобнее использовать раздел «Дополнительные услуги и варианты». Перевод из этого раздела имеет приоритет перед переводом той же фразы интерфейса.
