# Contributing / Участие

Сообщайте об ошибках и предлагайте улучшения через GitHub Issues. Укажите версию плагина, Webasyst, Shop-Script, PHP, название темы, шаги повторения и ожидаемый результат. Не публикуйте пароли, ключи API, данные покупателей, заказы или полные дампы базы. Перед отправкой примеров JSON удалите частные данные.

Для изменения кода создайте fork и pull request с описанием и проверками. Сохраняйте совместимость с PHP 7.4.24 и условия LGPL-3.0-only. Не изменяйте исходные данные магазина ради перевода: переводы хранятся отдельно.

Report bugs and suggest improvements through GitHub Issues. Include plugin, Webasyst, Shop-Script, PHP, and theme versions, reproduction steps, and expected behavior. Never publish passwords, API keys, customer data, orders, or database dumps. Remove private data from sample JSON files.

For code changes, create a fork and pull request describing the change and validation. Keep PHP 7.4.24 compatibility and LGPL-3.0-only licensing. Store translations separately instead of overwriting original shop content.
