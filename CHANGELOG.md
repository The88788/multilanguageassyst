# Changelog / История изменений

## 0.6.18

### Русский

- Первый выпуск на GitHub, опубликован в каталогах Webasyst RU и COM.
- Русский и английский интерфейс плагина по языку пользователя Webasyst.
- Локализация статусов, ошибок проверки и стандартных старых записей журнала.
- Английские инструкции и три примера запросов для подготовки и проверки перевода.
- Контакты автора: сайт, Telegram, MAX и WhatsApp.

Возможности: ручной редактор, переводы товаров, категорий, страниц магазина, характеристик и значений, дополнительных услуг, фраз интерфейса и текстовых блоков поддерживаемых тем. Экспорт/импорт JSON, проверка исходных текстов, подтверждение замены и журнал последних 200 событий.

### English

- First GitHub release, published in the Webasyst RU and COM stores.
- Russian and English plugin backend, following the Webasyst user's language.
- Localized operation messages, validation errors, and recognized historical log entries.
- English documentation and three translation and review prompt examples.
- Author contacts: website, Telegram, MAX, and WhatsApp.

Features: manual translation editor for products, categories, shop pages, features and values, additional services, interface phrases, and text blocks in supported themes. JSON export/import, source validation, explicit overwrite confirmation, and a log of the latest 200 events.
